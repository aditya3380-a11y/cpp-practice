# cpp-practice

My C++ learning log — starting from zero, one week before my BTech (CSE & Data Science, GTBIT) orientation even begins.

I'm using this repo to track what I actually write and understand as I go, not just what I've watched in a tutorial. Expect small, simple programs at first — variables, operators, input/output, control statements — building up toward Data Structures & Algorithms.

## What's in here

- Basic syntax and variable practice
- Operators and expressions
- Input/output programs
- Control flow (if/else, loops)
- More added as I learn

## Why public

Mostly for myself — writing code I know others might see keeps me honest about actually understanding it, not just copying along. If you're learning too, or you spot something I got wrong, feel free to open an issue or reach out.
